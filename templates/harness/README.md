# Harness Templates

These files are the pristine forms shipped by `scripts/export.sh`. The repo-root
`CLAUDE.md`, `AGENTS.md`, and `Makefile` are this scaffold's own filled-in instance.

For contract changes to those files, update both the repo-root copy and the matching
template unless the change is intentionally template-only. See the existing gotcha in
the repo-root `CLAUDE.md`.
